Bobine Deploy rewritten as a native application: no WebView, no Tauri, no WebKit, no OpenSSL.

- One executable, three equivalent interfaces on the same engine: native window (iced, CPU rendering, works without
  a GPU), command line, and JSON-RPC 2.0 on stdio (`bobine-deploy rpc`) for scripts and automation tools.
- SSH in pure Rust (russh): host key checked against `known_hosts` before any password, then key, password,
  keyboard-interactive, and with consent the SSH agent and `~/.ssh` keys.
- The Linux binary only links the C library; display libraries are loaded at run time.
- Embeds `install.sh` from the signed Bobine V5.1.1 release.

Verify the downloads with `SHA256SUMS` and `SHA256SUMS.asc` (see
[SECURITY.md](https://github.com/FantasmaGlad/bobine-deploy/blob/main/SECURITY.md)).
