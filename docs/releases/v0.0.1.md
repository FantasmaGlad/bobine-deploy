First release of Bobine Deploy as a standalone project. The installation assistant previously shipped inside the
[Bobine](https://github.com/FantasmaGlad/Bobine) repository now lives here, with the same behavior.

- Renamed to Bobine Deploy: executable, packages and application identifier `bobine-deploy`. The `.deb` and `.rpm`
  packages replace `bobine-assistant`.
- Linux (`.deb`, `.rpm`), Windows (NSIS) and macOS (`.dmg`), each in x86_64 and ARM64.
- Embeds `install.sh` from the signed Bobine V5.1.1 release, checked at build time.
- No built-in self-update and no Android build in this version.

Verify the downloads with `SHA256SUMS` and `SHA256SUMS.asc` (see [SECURITY.md](https://github.com/FantasmaGlad/bobine-deploy/blob/main/SECURITY.md)).
